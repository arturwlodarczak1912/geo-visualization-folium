# Geographic Visualization of Airbnb Listings with Folium

## 🎯 Project Goal
Creating an interactive HTML map to visualize the geographical locations of Airbnb listings using the **Folium** library.

## 📊 Dataset
[Airbnb Prices in European Cities](https://www.kaggle.com/datasets/thedevastator/airbnb-prices-in-european-cities) (Kaggle)

## 🛠️ Key Tasks & Accomplishments
- Loading and preprocessing spatial data (latitude and longitude coordinates).
- Building an interactive map with customized markers using `folium`.
- Exporting the rendered map as a standalone HTML web page.

## 🧰 Tech Stack
`Python` `Pandas` `Folium` `Kaggle API`

## ⚙️ How to Run
```bash
pip install pandas folium kaggle
jupyter notebook folium-airbnb.ipynb
